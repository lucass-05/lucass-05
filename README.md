## Proyectos

### [ProyectoFarmacia](https://github.com/lucass-05/ProyectoFarmacia) · repositorio privado
Gestión completa de fórmulas magistrales para una oficina de farmacia, en uso real:
tasación automática según el Concierto farmacéutico de Asturias, stock por lotes e
impresión de etiquetas y documentación oficial. Full-stack con React, TypeScript,
Node.js y SQLite.

### [KanaMe](https://github.com/lucass-05/KanaMe) · [▶ Probar](https://lucass-05.github.io/KanaMe/)
Quiz interactivo para aprender japonés (hiragana, katakana y kanji N5), con modo de
práctica libre y modo examen con nota. React 19, TypeScript, Vite y Tailwind,
desplegado con GitHub Actions.

### [DontKillMyDate](https://github.com/minilina/DontKillMyDate) · [▶ Jugar](https://minilina.github.io/DontKillMyDate/)
Videojuego web hecho en equipo (asignatura de Desarrollo de Videojuegos, FDI UCM):
encarnas a una hechicera que prepara pociones a contrarreloj para salvar las citas
de sus clientes. JavaScript puro, con tráiler y arte propio.
